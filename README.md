# Um Olhar de Quem Está no Campo

**Pesquisa de campo e análise exploratória sobre as experiências e percepções de profissionais de tecnologia.**

![Capa do projeto](imagens/card_readme.jpeg)

## Sobre o projeto

*Um Olhar de Quem Está no Campo* é uma pesquisa voltada à compreensão das experiências, percepções e trajetórias de profissionais de tecnologia.

A proposta é investigar o que os dados revelam sobre as pessoas que constroem suas trajetórias nesse campo, considerando suas experiências, escolhas, desafios e perspectivas.

O projeto também constitui um exercício prático de aplicação de técnicas de análise de dados, desde a organização da base até a exploração dos resultados e o desenvolvimento de visualizações.

## Objetivos

- Investigar as percepções e experiências de profissionais de tecnologia.
- Organizar e explorar os dados coletados em pesquisa de campo.
- Identificar padrões, frequências e possíveis relações entre as respostas.
- Desenvolver visualizações que contribuam para a interpretação dos resultados.
- Transformar dados em informações relevantes para compreender experiências reais.

## Abordagem metodológica

O trabalho parte de uma pesquisa de campo realizada por meio de formulário.

A análise segue um processo exploratório e progressivo:

1. **Coleta:** obtenção das respostas por meio do formulário.
2. **Organização:** estruturação e leitura da base de dados em formato CSV.
3. **Inspeção:** verificação inicial dos dados, das variáveis e das respostas registradas.
4. **Tratamento:** identificação e preparação dos dados conforme as necessidades de cada análise.
5. **Análise exploratória:** investigação de frequências, distribuições e padrões nas respostas.
6. **Visualização:** construção de representações gráficas para apoiar a interpretação dos resultados.
7. **Comunicação:** organização dos achados em um relatório digital.

As etapas são documentadas para manter a rastreabilidade das decisões analíticas.

## Tecnologias e ferramentas

- **Python:** linguagem utilizada na exploração e análise dos dados.
- **Pandas:** leitura, organização, transformação e análise de dados tabulares.
- **Jupyter Notebook:** ambiente interativo para executar código, observar resultados e registrar etapas da análise.
- **Git e GitHub:** controle de versão e documentação da evolução do projeto.
- **HTML:** formato previsto para a apresentação do relatório final.

As ferramentas poderão ser ampliadas conforme o desenvolvimento do trabalho.

Os dados não são um fim em si mesmos. São registros de experiências humanas que precisam ser contextualizados e interpretados.
